# NEXORA

Plateforme de gestion du courrier et des documents du secrétariat de l'École nationale d'administration de Côte d'Ivoire.

- Registre des courriers arrivée et départ, numéro d'ordre automatique (ARR-AAAA-0001 / DEP-AAAA-0001)
- Scans archivés, circuit de transmission, agenda et rappels
- Rapports jour / semaine / mois / année (PDF) et export Excel du registre
- Lecture automatique des courriers scannés (fonction `lire-courrier`, à activer)

Application web statique (HTML, CSS, JavaScript) reliée à Supabase. Déployée sur GitHub Pages.
